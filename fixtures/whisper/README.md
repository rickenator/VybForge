# fixtures/whisper — reference artifacts for the STT slice

Everything here is generated by the oracle scripts in this directory; nothing is
runtime code. The oracle runs the real model (transformers + torch) and the Vyb
implementation is compared against it — the comparison never runs the other way,
which is what keeps it an independent check rather than a mirror.

| Script | Produces |
|---|---|
| `oracle_mel.py` | `native/mel/gold/` — mel reference + FFT vectors (see that directory) |
| `oracle_stt.py` | `gold_stt/` — staged encoder/decoder tensors, prompt, logits, greedy ids, reference text |
| `oracle_weights.py` | `gold_stt/weights_listing_ref.txt` — an independent checkpoint inventory |

Run them with `~/miniconda/bin/python` (torch 2.7 + transformers 4.52; the
`~/llm-venv` there has a huggingface-hub/transformers version clash and the
VybForge `.venv` has numpy only).

Audio fixture: `../audio/jfk.wav` is the 16 kHz mono sample shipped with
ggml-org/whisper.cpp (MIT), used because its transcript is unambiguous and widely
reproduced — a good token-for-token target.

The `.f32` tensor dumps are gitignored (35 MB, regenerable); the listings and
reference text are small and tracked.
